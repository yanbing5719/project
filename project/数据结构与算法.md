# 树（n个节点构成的有限集合）
- n=0被称为空树
- 有且只有一个根节点
- 其余节点可分为m个互不相交的子集，每个子集也是树，根节点的子树
## 树的基本术语
- 节点间的关系
双亲与孩子   兄弟    祖先   子孙
- 树的高度=树的深度=树的层数
- 节点的深度：他所在的层次
- 结点的高度：以他为根的子树的层数
- 节点的度：孩子的数（度为零的节点叫做叶结点，大于零的结点叫分支结点）
- 树的度：树中结点的最大度数
度为m的数：至少有一个节点的度=m
m叉数：所有的结点的度可以都小于m，甚至可以是空树
- 有序树:各结点的子树从左到右有序不能互换
- 森林：m棵互不相交树的集合
## 树的性质
- 结点数=边数+1=所有结点度数之和+1
- m叉树第i层最多有$m^{i-1}$ 个结点
- 高度为h的m叉树最多有$$\frac{m^{h}-1}{m-1}$$ 个结点
- 高度为h的m叉数最少有h个结点都为1
- 度为m，高度为h的树最少有h-1+m个结点
# 二叉树

**数组采用动态申请的方式** ----动态顺序表
```c
//将1～10放入顺序表中
#include <iostream>
#include <cstring>
using namespace std;
int main(){
    int *a ;//接受数组的地址
    int capacity; //数组的容量
    int n;//标记有效数组的元素个数
    a=new int [5];
    capacity=5;
    n=0;
    for(int i=1;i<=10;i++){
         //扩容
        if(n==capacity){
            int *t=new int [capacity*2];
            memcpy(t,a,sizeof(int)*capacity);
            delete [] a;
            a=t;
            capacity*=2;
        }
        a[n]=i;
        n++;
    }
    for(int i=0;i<n;i++){
        cout<<a[i]<<' ';
    }
    delete [] a;
    return 0;
}
   ```
**数组采用静态申请方式**  ----静态顺序表顺序表一般将第一个元素放在下标为1的上面
```c
#include <iostream>
 const int N=100000;
using namespace std;
//静态封装顺序表
class SqList
{
   int a[N];
   int n;//元素个数
   public: 
   SqList(){
    n=0;
   }
   //顺序表的尾插法
   void push_back(int x){
    a[++n]=x;
   }
   //顺序表的头插法
   void push_front(int x){
      for(int i=n;i>=0;i--){
        a[i+1]=a[i];
      }
      a[1]=x;
      n++;
   }
   //在任意位置插入元素
   void insert(int p,int x){
    for(int i=n;i>=p;i--){
        a[i+1]=a[i];
    }
    a[p]=x;
    n++;
   }
   //删除表尾的元素
   void pop_back(){
    n--;
   }
   //删除表头的元素
   void pop_front(){
    for(int i=2;i<=n;i++){
        a[i-1]=a[i];
    }
    n--;
   }
   //删除任意位置的元素
   void erase(int p){
    for(int i=p+1;i<=n;i++){
        a[i-1]=a[i];
    }
    n--;
   }
   //查找元素-按值查找
   int find(int x){
    for(int i=0;i<n;i++){
        if(a[i]==x){
            return i;
        }
    }
    return -1;
   }
   //查找元素-按下标查找
   int get(int p){
    return a[p];
   }
   //打印顺序表
   void print( ){
    for(int i=0;i<=n;i++){
        cout<<a[i]<<' ';
    }
    cout<<endl<<endl;
   }
};
```
