## printf的返回值和输出值
`printf` 函数的**返回值**和**输出内容**是两个完全不同的概念，主要区别如下：
### 1. 本质不同
- **输出内容**：是 `printf` 函数向标准输出设备（通常是屏幕）打印的**可见字符序列**，由格式字符串和对应参数决定。  
  例如 `printf("a=%d", 10)` 的输出内容是屏幕上显示的 `a=10`。

- **返回值**：是 `printf` 函数执行成功后**返回的一个整数**，表示本次调用实际打印的**字符总数**（包括所有字符，如数字、字母、符号、空格、换行符 `\n` 等）。  
  例如 `printf("a=%d", 10)` 输出的 `a=10` 共 4 个字符（`a`、`=`、`1`、`0`），因此返回值为 `4`。
  ### 2. 用途不同
- **输出内容**：是函数的**主要功能**，用于向用户展示信息（如数据、提示文本等），是直观可见的结果。
  
- **返回值**：是函数执行状态的**辅助反馈**，主要用于程序内部判断输出是否成功（例如返回值为负数时表示输出失败，通常由错误导致）。  
  例如：
  ```c
  int ret = printf("test");
  if (ret < 0) {
      // 输出失败的处理逻辑
  }
  ```
  ### 3. 表现形式不同
- **输出内容**：直接显示在标准输出设备（屏幕）上，是用户能直接看到的字符串。
  
- **返回值**：不会主动显示，需要通过变量接收后显式打印才能看到。  
  例如：
  ```c
  int num = printf("hello"); // 输出 "hello"，返回值 5 存储在 num 中
  printf("\n返回值是：%d", num); // 显式打印返回值，输出 "返回值是：5"
  ```
### 总结
- `printf` 的**输出**是“打印到屏幕的内容”，是函数的核心功能，用于信息展示。  
- `printf` 的**返回值**是“打印的字符总数”（或错误标识），是函数的执行结果反馈，用于程序内部判断。  

两者没有直接关联，返回值不包含输出内容本身，仅表示输出内容的长度（成功时）。
## 字符串
1.  **strcmp(p1, p2)** 用来比较两个字符串，比较ACALL码。它逐个字符地比较 p1 和 p2，直到遇到不同的字符或字符串结束符 \0。如果字符串相等，strcmp 返回0；如果不同，则返回非零值。
2. **sizeof** 是一个编译时运算符，它计算的是类型或变量的总字节数，包括数组中的所有元素（包括结尾的 \0）。
3. **strlen** 是一个库函数，用来计算字符串（以 \0 结尾的字符数组）的长度，不包括结尾的 \0。
## 按位运算
1. **按位与（&）**：只有对应的位都为1时，结果才为1，否则为0。
    
2. **按位或（|）**：对应的位只要有一个为1，结果就为1，只有都为0时，结果才为0。
    
3. **按位异或（^）**：对应的位相同为0，不同为1。
    
4. **按位取反（~）**：把所有二进制位反转，0变1，1变0。
    
5. **左移（<<）**：将所有位向左移动，左移一位相当于乘2。
    
6. **右移（>>）**：将所有位向右移动，右移一位相当于除2。
## const 与指针

```c
struct P {
    int x;
    //常量整数，不可改变y的数值。
    const int y;
};

int main() {
    struct P p1 = { 10, 20 }, p2 = { 30, 40 };
    //定义了const类型的常量，p3内容不可改变。
    const struct P p3 = { 50, 60 };
    //常量指针，只能指向p1.
    struct P* const ptr1 = &p1;
    //指向常量结构体的指针，p2的内容不可修改。
    const struct P* ptr2 = &p2;
    //ptr3不可改变指向，p3的内容也不可修改。
    const struct P* const ptr3 = &p3;
    return 0;
}
```
## 全局变量与静态变量
| 特性        | 全局变量       | 静态变量                                   |
| --------- | ---------- | -------------------------------------- |
| **生命周期**  | 从程序开始到程序结束 | 从程序开始到程序结束                             |
| **作用域**   | 整个程序       |  局部静态变量：仅限于声明它的函数<br> 全局静态变量：仅限于当前文件 |
| **初始化**   | 自动初始化为零    | 自动初始化为零（如果未显式初始化）                      |
| **存储位置**  | 数据段        | 数据段（静态局部变量或全局静态变量）                     |
| **外部可见性** | 可以被其他文件访问  |  局部静态变量(函数内部声明）：无法被外部访问<br> 全局静态变量（函数内部声明）：仅限于当前文件访问 |
---
- 在 C 语言中，当局部变量与全局变量同名时，局部变量会在其作用范围内 “屏蔽”（hide）全局变量，这种现象称为 “变量的作用域屏蔽” 或 “名字隐藏”。
## 对两个数组进行拼接，排序，去重
```1#include <stdio.h>
#include <stdlib.h>
struct result {
	int* arr;
	int len;
};
void your_concat(int arr1[], int len1, int arr2[], int len2, struct result* res) {
	res->len = len1 + len2;
	res->arr = malloc(res->len * sizeof(int));
	for (int i = 0; i < len1; i++) {
		res->arr[i] = arr1[i];
	}
	for (int i = 0; i < len2; i++) {
		res->arr[len1 + i] = arr2[i];
	}
}
void your_sort(struct result* res) {
	for (int i = 0; i <res->len-1; i++) {
		for (int j = 0; j < res->len - 1 - i; j++) {
			if (res->arr[j] > res->arr[j + 1]) {
				int t = res->arr[j];
				res->arr[j] = res->arr[j + 1];
				res->arr[j + 1] = t;
			}
		}
	}
}
void your_dedup(struct result* res) {
	int k = 0;
	if (res->len == 0) {
		return;
	}
	for (int i = 1; i < res->len; i++) {
		if (res->arr[k] != res->arr[i]) {
			k++;
			res->arr[k] = res->arr[i];
		}
		
	}
	res->len = k + 1;
}
void print_result(struct result* res) {
	for (int i = 0; i < res->len; i++) {
		printf("%d ", res->arr[i]);
	}
	printf("\n");
}
int main() {
	int arr1[] = { 6, 1, 2, 1, 9, 1, 3, 2, 6, 2 };
	int arr2[] = { 4, 2, 2, 1, 6, 2 };
	int len1 = sizeof(arr1) / sizeof(arr1[0]);
	int len2 = sizeof(arr2) / sizeof(arr2[0]);

	struct result result;
	your_concat(arr1, len1, arr2, len2, &result);
	print_result(&result);
	your_sort(&result);
	print_result(&result);
	your_dedup(&result);
	print_result(&result);
	free(result.arr);
	return 0;

}
```
## 结构体和联合体

| 特性       | 结构体 (`struct`)  | 联合体 (`union`)        |
| -------- | --------------- | -------------------- |
| **内存分配** | 每个成员都有独立的内存空间   | 所有成员共用同一块内存空间        |
| **内存对齐**   | 成员大小的总和，总大小必须满足最大成员的整数倍| 最大成员的大小，总大小必须满足最大成员的整数倍  |
| **存取方式** | 每个成员独立存取        | 同一时刻只能存取一个成员         |
| **适用场景** | 存储多个独立的数据  （统一物质的不同属性）     | 存储不同类型数据但只用一个成员在某个时刻（一个属性的多种类型） |
| **内存效率** | 较低（因为每个成员都占用内存） | 较高（因为只分配最大成员的内存空间）   |
## 柔性数组

柔性数组必须是结构体的最后一个成员，并且它没有指定的长度。需要手动为他分配内存。由于结构体通常会包含其他固定大小的成员，柔性数组提供了一种方式来扩展结构体的内存布局，从而避免浪费内存空间。
## 无符号整型

 - 1.**取值范围** 无符号整型，取值范围是 （0 ~ 2³² - 1），所有位都用于表示数值，没有符号位。
  - 2.**没有负数**
   无法表示负数，若强制给 unsigned int 赋值负数（如 unsigned int a = -1），会发生溢出，结果是该负数对应的 “无符号等价值”（例如 -1 会被解析为 4294967295，即 2³² - 1）。
   - 3.**溢出行为**
   当运算结果超出取值范围时，会自动对 2^n（n 为位数）取模。例如： unsigned int a = 4294967295; a++; → a 会变成 0（因为 4294967295 + 1 = 2³²，对 2³² 取模后为 0）。 unsigned int a = 0; a--; → a 会变成 4294967295（下溢后取模）。无符号整型的取值范围就像一个 “环”，最大值加 1 回到 0，0 减 1 回到最大值
## 整型和浮点型的转化
- 隐式转化：编译器自动进行，通常发生在混合运算或赋值时，遵循 “低精度向高精度转化” 原则（如 int → float → double）。
- 1.计算机用二进制存储浮点数（float/double），但像 0.1（十进制）转换为二进制是无限循环小数（0.0001100110011...）。
- 2.浮点数存储位数有限（float 32 位、double 64 位），会截断这个无限循环小数，导致存储的是 “近似值” 而非精确值。
- 3.转为整形时小数部分被截掉，掩盖了误差。
## 递归分治的思路（“怎么算”）
“**递归分治**” 是指函数通过以下步骤处理数组：
• **递归拆分**：把整个数组区间不断 “二分” 成更小的子区间（比如把 [0-10] 拆成 [0-5] 和 [6-10]，再继续拆更小的区间），直到子区间只剩一个元素（无法再拆分）。
• **分治合并**：从最小的子区间（单个元素）开始，逐步合并相邻的两个子区间的结果，最终得到整个数组的结果。

## sprintf
sprintf()声明在stdio.h中，把数据写入字符串，而不是打印在显示器上。因此该函数可以把多个元素组合成一个字符串，sprintf 返回值是写入的字符数（不包括 \0）。sprintf()第一个参数是目标字符串的地址，其余与printf()相同。
## static
用于改变变量或函数的 存储周期 和 作用域。被他修饰的对象有静态储存期，只分配一次内存，并在程序结束时才释放。（生命周期=整个程序运行过程）。


- 局部静态变量：让其在函数调用后保留调用后的值，作用域仅在该函数内部，延长了生命周期但是作用域不变。
- 全局静态变量：生命周期为程序开始到程序结束，只能在定义他的源文件内可见。
- 静态函数：生命周期与普通函数一样，作用域仅限于定义他的源文件，使得其他源文件无法调用该函数，将函数的实现细节隐藏，提高安全性。
- 静态指针： static int *p = NULL;定义在函数里，函数退出后p不会被销毁，保留上次的地址。（静态指针不会自动释放其所指内存，程序结束时由系统回收）
- 修饰被指向的对象：static int data =100； int *p = &data;
p可以被传递但是data一直存在。
- 内存分配到数据段。
