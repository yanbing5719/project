## printf的返回值和输出值
`printf` 函数的**返回值**和**输出内容**是两个完全不同的概念，主要区别如下：
### 1. 本质不同
- **输出内容**：是 `printf` 函数向标准输出设备（通常是屏幕）打印的**可见字符序列**，由格式字符串和对应参数决定。  
  例如 `printf("a=%d", 10)` 的输出内容是屏幕上显示的 `a=10`。

- **返回值**：是 `printf` 函数执行成功后**返回的一个整数**，表示本次调用实际打印的**字符总数**（包括所有字符，如数字、字母、符号、空格、换行符 `\n` 等）。  
  例如 `printf("a=%d", 10)` 输出的 `a=10` 共 4 个字符（`a`、`=`、`1`、`0`），因此返回值为 `4`。
  ### 2. 用途不同
- **输出内容**：是函数的**主要功能**，用于向用户展示信息（如数据、提示文本等），是直观可见的结果。
  
- **返回值**：是函数执行状态的**辅助反馈**，主要用于程序内部判断输出是否成功（例如返回值为负数时表示输出失败，通常由错误导致）。  
  例如：
  ```c
  int ret = printf("test");
  if (ret < 0) {
      // 输出失败的处理逻辑
  }
  ```
  ### 3. 表现形式不同
- **输出内容**：直接显示在标准输出设备（屏幕）上，是用户能直接看到的字符串。
  
- **返回值**：不会主动显示，需要通过变量接收后显式打印才能看到。  
  例如：
  ```c
  int num = printf("hello"); // 输出 "hello"，返回值 5 存储在 num 中
  printf("\n返回值是：%d", num); // 显式打印返回值，输出 "返回值是：5"
  ```
### 总结
- `printf` 的**输出**是“打印到屏幕的内容”，是函数的核心功能，用于信息展示。  
- `printf` 的**返回值**是“打印的字符总数”（或错误标识），是函数的执行结果反馈，用于程序内部判断。  

两者没有直接关联，返回值不包含输出内容本身，仅表示输出内容的长度（成功时）。

## 按位运算（只适用于整形数据）
1. **按位与（&）**：只有对应的位都为1时，结果才为1，否则为0。
掩码：用于检验特定位是0还是1；00000010&10010110=00000010
第1位是1还是0。
x&1=x  x&0=0;

2. **按位或（|）**：对应的位只要有一个为1，结果就为1，只有都为0时，结果才为0。
 打开位：   把特定的一个位设置为1,其他位不变00001111 | 10110110=10111111,把特定位设置为1，其他位不变。
3. **按位异或（^）**：对应的位相同为0，不同为1。
    切换位：打开已关闭的位，关闭已打开的位。00001111^10110110=10111001
4. **按位取反（~）**：把所有二进制位反转，0变1，1变0。
关闭位：   00001111 &～10110110=00001001,（先取反）将特定位设置为0,其他位不变。
5. **左移（<<）**：将所有位向左移动，左移一位相当于乘2。
    number<<2,number*$2^n$
6. **右移（>>）**：将所有位向右移动，右移一位相当于除2。
number>>2,number/$2^n$
## 位字段
位字段是一种用于高效打包多个小数据到单个整数中的语法工具。
它的主要优点是节省内存和提高代码可读性。其他与结构体差不多。
```c
#include <stdio.h>

// 用一个结构体存储日期，假设年份范围是 0-9999，月份1-12，日期1-31
struct date_packed {
    unsigned int year : 13;  //13个比特位 2^13 = 8192，足够表示 0-9999
    unsigned int month : 4;  // 2^4 = 16， 足够表示 1-12
    unsigned int day : 5;    // 2^5 = 32， 足够表示 1-31
}; // 总共 13 + 4 + 5 = 22 位

// 对比：用普通整数存储的日期
struct date_normal {
    unsigned int year;  // 通常占 4 字节
    unsigned int month; // 通常占 4 字节
    unsigned int day;   // 通常占 4 字节
};

int main() {
    printf("打包的日期结构体大小: %zu 字节\n", sizeof(struct date_packed));   // 输出 4 (22位 < 32位)
    printf("普通的日期结构体大小: %zu 字节\n", sizeof(struct date_normal));   // 输出 12

    struct date_packed today = {2024, 7, 19};
    printf("今天是 %u年%u月%u日\n", today.year, today.month, today.day);

    return 0;
}
```

## static
用于改变变量或函数的 存储周期 和 作用域。被他修饰的对象有静态储存期，只分配一次内存，并在程序结束时才释放。（生命周期=整个程序运行过程）。


- 局部静态变量：让其在函数调用后保留调用后的值，作用域仅在该函数内部，延长了生命周期但是作用域不变。
- 全局静态变量：生命周期为程序开始到程序结束，只能在定义他的源文件内可见。
- 静态函数：生命周期与普通函数一样，作用域仅限于定义他的源文件，使得其他源文件无法调用该函数，将函数的实现细节隐藏，提高安全性。
- 静态指针： static int *p = NULL;定义在函数里，函数退出后p不会被销毁，保留上次的地址。（静态指针不会自动释放其所指内存，程序结束时由系统回收）
- 修饰被指向的对象：static int data =100； int *p = &data;
p可以被传递但是data一直存在。

## 对两个数组进行拼接，排序，去重
```c
#include <stdio.h>
#include <stdlib.h>
struct result {
	int* arr;
	int len;
};
void your_concat(int arr1[], int len1, int arr2[], int len2, struct result* res) {
	res->len = len1 + len2;
	res->arr = malloc(res->len * sizeof(int));
	for (int i = 0; i < len1; i++) {
		res->arr[i] = arr1[i];
	}
	for (int i = 0; i < len2; i++) {
		res->arr[len1 + i] = arr2[i];
	}
}
void your_sort(struct result* res) {
	for (int i = 0; i <res->len-1; i++) {
		for (int j = 0; j < res->len - 1 - i; j++) {
			if (res->arr[j] > res->arr[j + 1]) {
				int t = res->arr[j];
				res->arr[j] = res->arr[j + 1];
				res->arr[j + 1] = t;
			}
		}
	}
}
void your_dedup(struct result* res) {
	int k = 0;
	if (res->len == 0) {
		return;
	}
	for (int i = 1; i < res->len; i++) {
		if (res->arr[k] != res->arr[i]) {
			k++;
			res->arr[k] = res->arr[i];
		}
		
	}
	res->len = k + 1;
}
void print_result(struct result* res) {
	for (int i = 0; i < res->len; i++) {
		printf("%d ", res->arr[i]);
	}
	printf("\n");
}
int main() {
	int arr1[] = { 6, 1, 2, 1, 9, 1, 3, 2, 6, 2 };
	int arr2[] = { 4, 2, 2, 1, 6, 2 };
	int len1 = sizeof(arr1) / sizeof(arr1[0]);
	int len2 = sizeof(arr2) / sizeof(arr2[0]);

	struct result result;
	your_concat(arr1, len1, arr2, len2, &result);
	print_result(&result);
	your_sort(&result);
	print_result(&result);
	your_dedup(&result);
	print_result(&result);
	free(result.arr);
	return 0;

}
```
## 结构体和联合体

| 特性       | 结构体 (`struct`)  | 联合体 (`union`)        |
| -------- | --------------- | -------------------- |
| **内存分配** | 每个成员都有独立的内存空间   | 所有成员共用同一块内存空间        |
| **内存对齐**   | 成员大小的总和，总大小必须满足最大成员的整数倍| 最大成员的大小，总大小必须满足最大成员的整数倍  |

| **适用场景** | 存储多个独立的数据  （统一物质的不同属性）     | 存储不同类型数据但只用一个成员在某个时刻（一个属性的多种类型） |

## 柔性数组

柔性数组必须是结构体的最后一个成员，并且它没有指定的长度。需要手动为他分配内存。由于结构体通常会包含其他固定大小的成员，柔性数组提供了一种方式来扩展结构体的内存布局，从而避免浪费内存空间，且访问其中元素时和数组一样不需要向指针一样解引用比较麻烦，只需分配一次内存。
## 无符号整型

 - 1.**取值范围** 无符号整型，取值范围是 （0 ~ 2³² - 1），所有位都用于表示数值，没有符号位。
  - 2.**没有负数**
   无法表示负数，若强制给 unsigned int 赋值负数（如 unsigned int a = -1），会发生溢出，结果是该负数对应的 “无符号等价值”（例如 -1 会被解析为 4294967295，即 2³² - 1）。
   - 3.**溢出行为**
   当运算结果超出取值范围时，会自动对 2^n（n 为位数）取模。例如： unsigned int a = 4294967295; a++; → a 会变成 0（因为 4294967295 + 1 = 2³²，对 2³² 取模后为 0）。 unsigned int a = 0; a--; → a 会变成 4294967295（下溢后取模）。无符号整型的取值范围就像一个 “环”，最大值加 1 回到 0，0 减 1 回到最大值
## 整型和浮点型的转化
- 隐式转化：编译器自动进行，通常发生在混合运算或赋值时，遵循 “低精度向高精度转化” 原则（如 int → float → double）。
- 1.计算机用二进制存储浮点数（float/double），但像 0.1（十进制）转换为二进制是无限循环小数（0.0001100110011...）。二进制只能精确表示多个1/2的幂的和
- 2.浮点数存储位数有限（float 32 位、double 64 位），会截断这个无限循环小数，导致存储的是 “近似值” 而非精确值。
- 3.转为整形时小数部分被截掉，掩盖了误差。
## 递归分治的思路（“怎么算”）
“**递归分治**” 是指函数通过以下步骤处理数组：
• **递归拆分**：把整个数组区间不断 “二分” 成更小的子区间（比如把 [0-10] 拆成 [0-5] 和 [6-10]，再继续拆更小的区间），直到子区间只剩一个元素（无法再拆分）。
• **分治合并**：从最小的子区间（单个元素）开始，逐步合并相邻的两个子区间的结果，最终得到整个数组的结果。

## C语言的内存结构
- 栈：储存局部变量，函数调用的返回值，函数参数。执行代码（函数进栈变量存在，函数出栈变量消失）。**栈向下生长，低地址在上，高地址在下，先入栈在上，后入栈在下。** 视觉上：栈底在上方，栈顶在下方，数据"从上往下"堆积。
- 堆：动态分配的内存。**生长方向与栈相反。**
- 数据段：初始化静态区（已经赋值的全局变量，静态变量）未初始化静态区（没有赋值的全局变量，静态变量）常量区（用指针定义的字符串）
**常量区**：内容不可修改，数据会进行复用
- BBS：数据段的一部分，储存未初始化的全局变量，静态变量。
- 代码段：临时储存代码（从上往下检查代码），只读

## 时间复杂度
- 时间复杂度是用来衡量一个算法执行所需时间随着输入数据规模增大而增长的趋势。它关注的不是具体的秒数，而是增长的速度。
-  不同情况下的时间复杂度

| 时间复杂度    | 术语           | 对数据规模 n=1000 的感性认识       |
|---------------|----------------|-----------------------------------|
| **O(1)**      | 常数时间       | 瞬间完成，与数据量无关            |
| **O(log n)**  | 对数时间       | 几乎瞬间完成，操作约10次          |
| **O(n)**      | 线性时间       | 需要处理1000个元素，可以接受（便利数组）      |
| **O(n log n)**| 线性对数时间   | 需要处理约10000次，效率不错       |
| **O(n²)**     | 平方时间       | 需要处理100万次，开始变慢 （排序算法，递归）       |
| **O(2ⁿ)**     | 指数时间       | 天文数字，完全不可行（斐波那契数列的暴力递归解法）

## malloc分配内存
- malloc返回一个指向void的指针，通常该函数的返回值会被强制转换为匹配的类型。
- 如果分配失败返回空指针。，或者调用exit()函数结束程序（EXIT_SUCESS相当于0  EXIT_FAILURE程序结束）
- 使用完后要用free()函数释放内存，如果忘记释放，上次的指针已经销毁，但内存仍然存在，则之后无法访问该内存，也不能重复使用，最终耗尽所用内存导致内存泄漏。

## 结构体和联合体的内存对齐
 - 结构体
    1. 每个成员有独立的内存地址
    2. 内存对齐：成员按自身大小对齐
    3. 总大小是最大对齐数的整数倍
    4. 可以同时访问所有成员
    5. 所有数据同时有效，每个数据独立访问和修改
 - 联合体
- 所有成员共享起始地址
 - 大小由最大成员决定
 - 同一时间只能使用一个成员
 - 修改一个成员会影响其他成员
 - 节省空间，同一时间段只有一个数据有效，修改一个数据会影响其他数据

## 深浅拷贝
- 浅拷贝 (Shallow Copy)

    只复制指针本身，不复制指针指向的数据

    新旧对象共享同一块内存

    修改一个会影响另一个

- 深拷贝 (Deep Copy)

    复制指针和指针指向的数据

    新旧对象有各自独立的内存空间

    修改一个不会影响另一个
